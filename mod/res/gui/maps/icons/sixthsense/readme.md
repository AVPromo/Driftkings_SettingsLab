# Packaged Sixth Sense icons

Use valid PNG images named `<number>.png` (for example `10.png`). The settings panel uses the numeric filename as the icon ID. Declare added images in `build_data/components.json` and keep them below the updater inventory's `MAX_FILE` limit. `assets.exclude` excludes this README.

Users can instead select `mods/configs/driftkings/sixthsense/SixthSenseIcon.png` through the existing custom-icon setting. Installer previews belong in `installer/setup/assets/previews/` and do not change the game payload.
